# Ping Single Column Coming Soon Page

A responsive coming soon page built with HTML, CSS, and JavaScript.

## Built With

- HTML5
- CSS3
- JavaScript
- Libre Franklin

## Preview

![Ping Coming Soon Page Screenshot](images/preview.jpg)


## Features

- Responsive design for desktop and mobile
- Email validation
- Error message for empty input
- Error message for invalid email format
- Hover and focus states
- Clean and accessible form

## What I Learned

This project helped me practice form validation with JavaScript.
I learned how to validate an email input when the form is submitted
and display an appropriate error message when the input is empty or invalid.

I also practiced building a responsive layout and matching a design
as closely as possible using CSS.

## Continued Development

I want to improve my form validation and responsive design skills
and continue building interactive JavaScript projects.
