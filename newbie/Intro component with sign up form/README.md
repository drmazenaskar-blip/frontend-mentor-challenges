# Intro Component with Sign Up Form

![Sign-up Form Screenshot](images/Screenshot%202026-09-18%20162145.png)

A responsive sign-up form built with HTML, CSS, and JavaScript.

## Built With

- HTML
- CSS
- JavaScript

## Features

- Form validation
- Email validation
- Show/hide password
- Responsive design
- Accessible form fields

## What I Learned

One of the main challenges was building the form validation.
I learned how to check empty fields and invalid email addresses, then show
the correct error state using JavaScript.

I also learned how to improve accessibility by using labels,
`aria-invalid`, and `aria-describedby`.

## Continued Development

I want to improve my form validation and accessibility skills
in future projects and build more interactive JavaScript projects.
